# SFT Pavilion Android

Official Android application for SFT Pavilion.

## Download

The public APK will be available from this repository's **Releases** page.

After the first release is published, the permanent latest-download address will be:

https://github.com/ictlab-interactive/sft-pavilion-android/releases/latest/download/SFT-Pavilion.apk

## Requirements

- Android device with an internet connection
- Notification permission for timetable reminders

## Security

Android signing keys, passwords, Firebase service-account files, and other secrets must never be committed to this public repository. Every future Android update must be signed with the same private release key.
